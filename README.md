# ridiculOSo
![Nathan](https://raw.githubusercontent.com/LuvlornDev/ridiculOSo/refs/heads/main/screenshot.png)
Our project is a crappy OS game about a guy who went to the flee market to get his computer full of pirated software so that he can emulate games from the New TomboStation 16 (since he doesn't have any money to buy it).

Our project is built in the GODOT Game Engine, and was originally designed for Desktop (Monitor 1920x1080).

We built this around the design of a real OS, so pretty much the mechanics of buttons and files is close enough to using a computer. With Browsers, a .txt file and a few other apps you can open and close.

You have to complete a series of "piracy" inspired puzzles to advance through the game.

This includes adware, eternal Terms and Conditions, countless CAPTCHAs and computer crashes.
